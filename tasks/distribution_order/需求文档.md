# **一、概述**

- 基于线下客户模块的合同档案数据，建立完善的分销订单生命周期管理闭环  合同这部分数据不需要考虑，我接入会
- 支持系统自动读取客户生效合同条款，并进行财务数值预计算（非精细）
- 实现订单的 **创建-报价审核-订单审核-预付款确认-下发（千易ERP）-履约监控-回款确认** 全流程状态跟踪
- 支持库存自动校验并在金额偏离（如低毛利）或库存不足时给与视觉高亮预警，以及支持分批发货（拆单）场景的单号自动延续生成

### **2.2.1 创建草稿**

- 点击【创建草稿】进入详情子页面
- 保存草稿
    - 点击后不校验任何必填项，订单数据直接保存并停留在【草稿】状态
- 提交审核
    - 提交后进入报价审核
- 作废
    - 点击后订单状态流转至【已作废】
- 模板下载和批量上传
    - 下载模板表头：SKU编码、含增值税报价、销售数量
    - 上传后解析，并计算相应的不含税单价等等联动字段

### **2.2.2 报价审核**

直线上级 + 分销主管（办事角色）二级审核

- 审核
    - 点击跳转订单详情页
    - 审批人可点击通过、驳回
    - 驳回时可以选择驳回至审批流前置的任何一环，必填驳回原因
    - 审批流需接入首页待办工作台
        - 审核流转到当前审核人时，创建一条待办给审核人，文案：
            - 分销订单：你有一条新的报价单待审核-提交审核日期【拼接日期】
        - 根据日期动态定义待办优先级
            - 报价单创建 不足2日 P2
            - 报价单创建 2-4日 P1
            - 报价单创建 4日以上 P0
- 撤回
    - 点击列表操作列【撤回】，弹出确认弹窗，文案为：订单撤回审核后，重新发起需要重新一环一环审核完，是否确认撤回？
    - 确认后订单状态流转回【草稿】

### **2.2.3 订单创建**

- 编辑
    - 点击列表操作列【编辑】跳转订单详情页，可编辑字段为2.0节标注填写时机为【订单创建】的字段
- 保存草稿
    - 点击后不校验任何必填项，订单数据直接保存并停留在【订单创建】状态
- 提交审核
    - 提交后进入订单审核
- 作废
    - 点击后订单状态流转至【已作废】

### **2.2.4 订单审核**

发起人提交订单审核，审批流进行中。根据订单金额判断审核层级：

| 订单金额（换算USD） | 审核层级 |
| --- | --- |
| 小于5000 USD | 直线上级 + 分销主管（办事角色） |
| 大于等于5000 USD | 直线上级 + 分销主管（办事角色） + CEO（办事角色）（TH订单在CEO前再加TH分销负责人办事角色） |
- 审核
    - 点击跳转订单详情页
    - 审批人可点击通过、驳回
    - 驳回时可以选择驳回至审批流前置的任何一环，必填驳回原因
    - 审批流需接入首页待办工作台
        - 审核流转到当前审核人时，创建一条待办给审核人，文案：
            - 分销订单：你有一个新的分销订单待审核-期望最晚出库日期【拼接日期】
        - 根据日期动态定义待办优先级
            - 期望最晚出库日期 距离当前日期 7自然日以上 P2
            - 期望最晚出库日期 距离当前日期 2-5自然日 P1
            - 期望最晚出库日期 距离当前日期 不足2自然日 P0
- 撤回
    - 点击列表操作列【撤回】，弹出确认弹窗，文案为：订单撤回审核后，重新发起需要重新审核，是否确认撤回？
    - 确认后订单状态流转回【草稿】

### **2.2.5 确认预付**

- 确认预付
- 点击列表操作列【确认预付】，弹出确认预付弹窗
- 可编辑字段为2.0节标注填写时机为【确认预付】的字段，确认后订单状态流转至待下发
- 需接入首页待办工作台
    - 审核流转到当前审核人时，创建一条待办给审核人，文案：
        - 分销订单：你有一个新的分销订单预付待确认-期望最晚出库日期【拼接日期】
        - 根据日期动态定义待办优先级
            - 期望最晚出库日期 距离当前日期 7自然日以上 P2
            - 期望最晚出库日期 距离当前日期 2-5自然日 P1
            - 期望最晚出库日期 距离当前日期 不足2自然日 P0

### **2.2.6 待下发**

- 下发
    - 校验分销库位可用库存是否充足：
        - 库存充足：推送订单至千易，订单状态流转至【履约中】，千易返回千易单号写入订单
        - 库存不足：Toast报错"可用库存不足，无法下发订单"，不允许下发
- 拆单
    - 可编辑字段为2.0节标注填写时机为【拆单】的字段
    - 拆单逻辑
        - 拆单后原订单扣减对应数量，生成子订单
        - 子订单单号规则：主单号 + 后缀（-A、-B、-C、-D……），如图所示
        - 拆单后不可合并
        - 子订单独立流转，各自进入【待下发】状态后分别下发

### **2.2.7 履约中**

- 确认实收
    - 可编辑字段为2.0节标注填写时机为【确认实收】的字段
    - 确认实收后，订单状态流转至【待回款】
    - 实收数量与订单数量不一致时，校验实收差异备注必填

### **2.2.8 待回款**

- 确认回款
    - 可编辑字段为2.0节标注填写时机为【确认回款】的字段
    - 需接入首页待办工作台
    - 订单抵达该状态时，创建待办给发起人，文案：
        - 分销订单：你有一个新的分销订单回款待确认-预计回款日期【拼接日期】
        - 根据日期动态定义待办优先级
            - 预计回款日期未到 P2
            - 预计回款日期 已到 0-3自然日 P1
            - 预计回款日期 已到 4自然日及以上 P0

### **撤回审核**

- 点击跳转订单详情页
- 发起人可点击【撤回审核】中止流程

### **确认预付/确认回款**

- 展示：WS单号、千易订单号、预付应付金额、尾款应付金额、预计回款日期
- 需填写：预付实收金额、预付款水单、预付款支付日期、尾款实付金额、实际回款日期、尾款水单、差异备注（在实收金额与应收金额有差异时，财务备注）

### **拆单**

- 展示：本订单销售的SKU编码、对应的销售单价、数量、该国主仓分销库位可用库存、根据拆单数量自动计算出的商品金额和订单金额
- 填入：拆单数量（需限制拆单数量不得大于销售数量）

### **下发**

点击下方，推送订单至千易。需校验可用库存是否充足，库存不足时点击下发，toast报错：可用库存不足，无法下发订单
