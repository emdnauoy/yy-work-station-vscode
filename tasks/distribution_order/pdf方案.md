# PDF 导入订单需求分析

## 1. 需求概述

特殊客户通过 PDF 采购单（PO）直接导入为分销订单，跳过报价阶段。

- 入口：新文件新接口
- 跳过：Draft(10)、Quote Review(20)
- 起始状态：Order Create(30)
- 导入后可手动编辑
- 审批流程正常走

## 4. 流程设计

```
上传 PDF（文件名 {customer_code}-{其他}.pdf）
    ↓
pdfplumber 解析 → 提取文本 + 表格
    ↓
解析头部信息 → customer_code (CT01), PO 编号, 日期
    ↓
按 PO 编号拆分为 N 个 order（待确认拆分规则）
    ↓
对每个 order:
    1. 文件名解析 → customer_code → 查 offline_customer 表
    2. 用户提供的函数 → 获取 snapshot 信息
    3. 生成 order_sn（正常流程）
    4. 跳过 quote_details
    5. 解析表格 → 生成 order_details
    6. 计算金额字段（待确认价格含税/不含税）
    7. status = 30（Order Create）
    ↓
返回结果 / 创建订单
```

## 6. 技术方案

### 依赖
- `pdfplumber`（已安装）

### 新增文件
- `pdf_import_service.py` — PDF 解析 + 订单创建逻辑
- `views/pdf_import.py` — 接口层
- `schemas.py` — 新增导入相关 schema

### 接口
- `POST /distribution_order/pdf/import/` — PDF 上传导入
  - 参数：`file`（UploadFile）
  - 返回：导入结果（成功/失败/预览数据）

### 错误处理
- PDF 解析失败 → 返回 40000 + 错误描述
- 客户编码未匹配 → 返回 40000
- 表格格式不识别 → 返回 40000 + 原始数据
- SKU 不存在 → 返回 40000 或跳过（待确认）
